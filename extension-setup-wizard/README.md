# Extension Setup Wizard

Plug-and-play go-live guide for the **Get Goods Gratis browser extension** (`gg-extension`).

- **`extension-setup-wizard.html`** — open in any browser. Walks: (1) load unpacked & test with the auth
  bridge, (2) flip the server gates (`EXTENSION_*` in Railway, counsel-gated), (3) publish to the Chrome Web
  Store and set `EXTENSION_WEBSTORE_URL`, (4) custom-domain wiring, then verify.

This is the 4th wizard, alongside API Setup, Setup/Domain/Deploy, and Launch Setup — surfaced together in
Bundle 38 under **`10 - Wizards`** as `Extension Setup Wizard.html`.
