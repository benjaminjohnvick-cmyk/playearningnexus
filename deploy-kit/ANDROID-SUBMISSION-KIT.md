# Android Submission Kit — Google Play

Your Capacitor wrapper is already built, so this is packaging + listing, not development. This kit
supplies the copy, the answers, and the signing steps so the developer isn't drafting them from
scratch. Target: **~10–13h** (down from 15–22h). Google Play fee: **$25 one-time**.

## Step 1 — Produce the signed app bundle (`.aab`)

You have two ways to build it. **Path A (cloud CI) needs no Android Studio and no local setup** — it's
the Android twin of the iOS-without-a-Mac flow, and it's simpler because Android builds on free Linux.

### One-time: create your upload keystore (no Android Studio)
Runs on any machine with a JDK (Windows/Mac/Linux) — or let CI hold it:
```bash
keytool -genkeypair -v -keystore upload.keystore -alias upload -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 upload.keystore     # copy this into the ANDROID_KEYSTORE_BASE64 secret (macOS: base64 -b0)
```
**Back up `upload.keystore` and its passwords** — you need the same key for every future update.

### Path A — Cloud CI (recommended, no Android Studio)
**GitHub Actions:**
1. Copy `deploy-kit/ci/android-build.yml` to `.github/workflows/android-build.yml`.
2. Add repo Secrets: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`,
   `ANDROID_KEY_PASSWORD` (and optionally `PLAY_SERVICE_ACCOUNT_JSON` to auto-publish).
3. Run the workflow (Actions tab → Run, or push to the `android-release` branch). It builds web →
   `cap sync android` → signs → produces `app-release.aab` as a downloadable artifact (and, if the Play
   secret is set, uploads to the Play **internal** track).

**Or Codemagic:** the `android-capacitor` workflow in `deploy-kit/ci/codemagic.yaml` does the same on
Codemagic's free Linux minutes — add the keystore + Play service account in its UI and run it.

### Path B — Local Android Studio (if you prefer a GUI)
```bash
npm run native:regenerate        # builds web + generates android/
npm run cap:open:android         # opens Android Studio
```
Then **Build → Generate Signed Bundle / APK → Android App Bundle**, create/select your keystore, build the release `.aab`.

## Step 2 — Play Console setup
1. Pay the **$25** one-time fee, create the app.
2. Upload the `.aab` to an **Internal testing** track first (fast review), test on a real device,
   then promote to Production.

## Step 4 — Data safety form (answer honestly to match the app)
- Collects: **email**, **account info**, **approximate/【if used】location**, **device identifiers**,
  **payment info** (processed by Stripe/PayPal — you don't store card numbers).
- Uses: app functionality, account management, fraud prevention, analytics.
- Shared with: payment processors (Stripe/PayPal), survey provider (BitLabs), email (SendGrid) — as processors.
- Encrypted in transit: **Yes**. Users can request deletion: **Yes** (link your account-deletion flow).

## Step 5 — Screenshots (specs)
- Phone: at least **2** (up to 8), PNG/JPG, 16:9 or 9:16, min 320px, max 3840px.
- Provide: home/dashboard, surveys list, games, rewards store, wallet. (Capture on a device or emulator.)
- Feature graphic: **1024 × 500** PNG/JPG.
- App icon: 512 × 512 (already generated by `npm run cap:assets` from `assets/icon.png`).

## Step 6 — Review notes (important for an earn-money app)
- Provide a **demo login** (test account with pre-loaded activity) in the review notes.
- State clearly: rewards are **merit/skill-based**, **not gambling**; no purchase required to earn.
- Confirm you have rights to the content and that payouts comply with your terms.
