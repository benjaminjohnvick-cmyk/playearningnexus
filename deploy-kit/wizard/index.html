5 · What to do with it (the click-path)

  1. Deploy the backend: click the Deploy on Railway button in the repo's README. Add a PostgreSQL database, set the backend service's Root Directory = backend, then paste the config above into the service's Variables. Railway builds and starts it for you.
  2. Turn on auto-deploy: in GitHub → Settings → Secrets and variables → Actions, add a secret RAILWAY_TOKEN (from Railway → account → Tokens). After that, every push to main deploys automatically and runs the QA check.
  3. Build the phone apps: in GitHub → Actions, run Android Build & Play / iOS Build & TestFlight (or push to the android-release / ios-release branch). Add the signing secrets listed at the top of each workflow first.
  4. Submit to the stores and pass review. This is the one part no tool can do for you.
